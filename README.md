## What is ContainerGuard?

ContainerGuard is a managed SaaS version of the open-source [Linux Autonomous Agent](https://github.com/muralipala1504/linux-autonomous-agent).

### Features

- 🔍 **Auto-Discovery** - Automatically discover all Docker containers
- 📊 **Live Metrics** - Real-time CPU, memory, disk monitoring
- 🔄 **Auto-Remediation** - Automatically restart unhealthy containers
- 🎯 **Full Control** - Stop, start, restart via API or dashboard
- 📝 **Audit Trails** - Complete action history with timestamps
- ⚡ **One-Command Deploy** - Works out of the box
